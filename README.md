# بوت سننشا تيليجرام 🤖

بوت متقدم لإدارة الحسابات والكليشات والكروبات مع مؤقت زمني تلقائي.

## ✨ المميزات
- ➕ اضافة/حذف حسابات تليجرام
- 📝 اضافة/حذف كليشات نصية
- 👥 اضافة/حذف كروبات
- ⏱️ تغيير المؤقت الزمني
- ▶️ تشغيل/⏹️ ايقاف البوت
- 📊 عرض الاحصائيات
- 🗄️ قاعدة بيانات SQLite
- 🔄 مؤقت في الخلفية

## 🚀 التشغيل المحلي

1. **تثبيت المكتبات:**
```bash
pip install -r requirements.txt
```

2. ضع التوكن في config.py:

```python
BOT_TOKEN = "توكن_البوت_هنا"
```

3. تشغيل البوت:

```bash
python bot.py
```

## 🌐 النشر على Railway

1. رفع المشروع على GitHub
2. ربطه مع Railway
3. اضافة متغيرات البيئة:
   - BOT_TOKEN = توكن البوت
   - ADMIN_ID = معرف المطور (اختياري)

## 📁 هيكل المشروع

```
سننشا-بوت/
├── bot.py              # الملف الرئيسي
├── config.py           # الإعدادات
├── database.py         # قاعدة البيانات
├── states.py           # حالات المستخدمين
├── scheduler.py        # المؤقت
├── requirements.txt    # المكتبات
├── Procfile           # لـ Railway
├── runtime.txt        # نسخة بايثون
└── data/              # مجلد البيانات
    └── database.db    # قاعدة البيانات
```

## 📝 ملاحظات

- المؤقت يعمل في الخلفية
- البوت يرسل أول كليشة في القائمة
- يمكن تغيير المؤقت بين 5-3600 ثانية
